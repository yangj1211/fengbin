# 丰宾电子 · 智能体工作台

五个智能工厂场景的前端 POC：33 客户推荐、29 设备维修、16 能源预测、10 生产洞察、37 供应商评估。

## 演示方式

选择左侧场景 → 选择一个示例问题 → 点击「运行演示」 → 查看「分析结果」「分析依据」「处理过程」。每个场景包含三个预设问题，支持重置。可编辑问题；自定义输入仅记录展示，并明确提示结果为固定样例。

## 范围

- 所有产品、设备、供应商、数值和案例均为虚构或匿名演示样例。
- 未连接真实 AI、数据库或业务系统，不上传用户输入。
- 场景范围依据工作区客户最终五项 Excel 与实例描述 DOCX；原始客户文件未包含在站点中。
- 三份资料标签表达演示资料类别，对应内置样例，当前不提供文件上传。

## 本地开发

Node.js 22.13+，使用 npm：`npm install`、`npm run dev`。生产构建：`npm run build`。检查：`npx tsc --noEmit`、`npx oxlint app`。

主页面位于 `app/page.tsx`，五场景数据在 `app/scenes.ts`，预设问题变体在 `app/answers.ts`，样式在 `app/globals.css`。

## 可选 WebMCP

支持该浏览器接口时注册 `select_demo_scene`，接受场景编号，使用和界面相同的动作切换场景。当前环境没有可调用的 WebMCP 验证上下文，未做该可选接口的运行时契约验证；普通浏览器操作不依赖它。本次未执行浏览器视觉或交互 QA。
