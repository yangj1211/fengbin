# 丰宾电子 · 智能制造平台

带独立管理员登录的业务应用前端。登录后直接进入智能体广场，五张卡片分别进入独立应用：客户与产品推荐、设备维修助手、能源预测与优化、生产洞察与预警、供应商绩效评估。

## 完整操作流程

每个智能体使用独立问答界面，支持示例问题、自然语言参数提取、上下文追问、停止分析和保存草稿。原始表单位于可展开的分析条件面板。提交问题后生成分析，可保存输入与结果快照、查看记录详情、填写跟进结果、标记完成、复用条件及导出。分析记录支持检索、筛选和删除。

数据管理覆盖五类资料：查看、编辑、新增、删除，下载 CSV 模板，上传后校验与预览，确认导入，导出和恢复示例内容。编辑后的数据参与后续分析，已保存结果保持原快照。

## 数据范围

本次完成应用前端和完整操作流程，尚未连接真实 AI 或业务系统。初始产品、设备、供应商和数值均为示例；结果由可查看依据的本地规则计算。每个智能体分别保存最近 20 轮问答。数据保存在当前浏览器的 localStorage，刷新可恢复，不跨设备同步。CSV 文件仅在浏览器读取，不上传。

五项场景依据工作区客户最终清单和实例描述，原始客户文件不包含在站点中。

## 开发与验证

Node.js 22.13+。本地启动：`npm run dev`。生产构建：`npm run build`。检查：`npx tsc --noEmit`、`npx oxlint app lib middleware.ts`。

`app/workspace.tsx` 为应用壳；`app/application/` 包含广场、五个智能体、分析记录、数据管理、业务计算和持久化。根页及 `app/[...path]/page.tsx` 在服务端保护应用路由。

验证覆盖五个模块计算、条件变化、空结果、CSV 导入导出、零用电边界、记录持久化及路由认证，并执行类型、静态检查与生产构建。未执行浏览器视觉或交互 QA。

## 管理员认证

`/login` 使用服务端验证的管理员账号。生产使用 Sites secrets `ADMIN_PASSWORD_HASH`、`ADMIN_SESSION_SECRET` 和配置 `ADMIN_USERNAME`；本地使用未提交的 `.dev.vars`。明文密码不进入源码或构建产物。

密码采用随机盐的 PBKDF2 SHA-256；会话采用独立密钥 HMAC 签名，Cookie 设置 HttpOnly、SameSite=Strict、HTTPS 下的 Secure，8 小时到期。修改密码记录或签名密钥会使现有会话失效。退出清除浏览器 Cookie；当前没有持久化的会话撤销表。登录接口检查 Origin、限制输入大小，并提供单个 Worker 实例内的失败次数限制。

托管平台访问权限独立于应用管理员登录，当前保留原有 Sites 私有访问设置。
