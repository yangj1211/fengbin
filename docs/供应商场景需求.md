# 第五场景：供应商绩效评估

帮助采购人员了解供应商表现，识别交付和来料质量的未达标项，并通过问答解释评分和差距。当前使用供应商汇总样例数据，支持看板与普通文字问答。

## 看板

保留评估供应商数量、平均综合评分、交付风险数量、质量风险数量四项概览，以及综合评分排行、供应风险分布、交付与质量对比三张图。供应商范围通过顶部选择器切换，点击评分排行或交付与质量图也可筛选当前供应商，指标与图表同步更新。

看板不展示供应商明细表、是否异常筛选、明细分页或导出。交付与质量风险通过概览和风险分布呈现，风险分布按每家供应商互斥归类；异常旁不提供提问、查看记录或其他操作入口。用户自行通过标题右侧的“智能问答”进入问答，查询具体供应商表现、评分和未达标项；不自动生成或发送问题。

标题区仅保留名称及“指标规则”“智能问答”两个入口，筛选栏只展示供应商范围。移除标题下方用途介绍、重复记录数量、常显规则段落，以及图表中重复的权重、分组和操作说明。风险指标保留95%与98%的简短阈值提示，数值单位、图例、评分满分及风险状态继续显示。

## 当前口径

- 综合评分＝交付及时率×40%＋来料合格率×40%＋响应评分×20%，满分100分。三项权重固定，不支持修改配置。
- 平均综合评分为各供应商综合评分的算术平均，每家权重相同。
- 交付及时率低于95%为交付风险，来料合格率低于98%为质量风险；等于目标不触发。两类风险可重叠，不能将两项风险数量相加当作异常供应商总数。
- 风险由是否达到交付和质量目标决定，与综合评分分别计算。权重和风险目标均固定使用默认规则。
- 95%、98%及40/40/20为样例设置，真实项目应由采购和质量要求确认，不作为行业标准。

评分公式、权重、平均分口径、风险阈值、互斥分组规则及数据边界集中在标题右侧的“指标规则”只读弹窗中。对话不能修改规则；旧草稿恢复时使用固定默认规则，历史回答保留当时结果。

默认样例：A评分98.04分，两项达标；B评分94.72分，交付及时率94%，低于目标1个百分点；C评分85.20分，交付及时率82%、来料合格率95%，分别低于目标13、3个百分点。交付风险2家、质量风险1家，共2家异常供应商。

## 问数与解释示例

| 类别 | 示例问题 | 回答内容 |
| --- | --- | --- |
| 评分与排名 | 哪家供应商评分最高？ | 当前评分、排序及权重 |
| 交付风险 | 哪些供应商交付未达标？ | 及时率、目标和差距 |
| 质量风险 | 哪些供应商来料质量需要关注？ | 合格率、目标和差距 |
| 供应商对比 | 对比供应商A和供应商C | 交付、质量、响应、综合评分及风险差异 |
| 评分与规则解释 | 供应商C的评分怎么算，为什么异常？ | 各项分数贡献、触发的具体规则 |

欢迎页仍保留三个样例卡片，能力覆盖不与卡片数量绑定。问答采用普通文字、段落和必要列表，不展示定制指标卡片、条件标签或操作按钮。参考数据集中在文末；保留问题复制、回答点赞/点踩/复制。旧对话按当时结果转换为文字，不重新计算历史值。

## 数据边界

当前字段为供应商、交付及时率、来料合格率、响应评分。比例由资料直接提供，没有订单数、到货批次、采购金额、日期、价格或原因记录，不能反推出逾期订单数、不良批次数，不能计算按订单数量加权的总体及时率，也不能确认异常原因或预测某笔订单一定延期。

问答可建议核对交付记录、检验报告和响应记录，但不声称已经找到这些明细。后续同名供应商的多条汇总比例不能在没有统计范围和分母的情况下直接合并。
