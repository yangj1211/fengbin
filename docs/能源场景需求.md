# 第三场景：能源预测与优化

原文要求围绕能耗趋势、对比、异常提醒、基础预测和节能建议提供轻量分析，至少支持三类分析视图。数据包括电、水、气等可取得的能源数据，以及日期、产量、班次、产线和设备状态。不做自动控制，不承诺预测精度。

## 现在实际实现

- 只有老化、含浸、其他三行工序用电汇总。没有日期、班次、产线、设备状态、水或气的明细。
- 按七天统计口径估算：汇总电量 × 预测天数 / 7 ×（1 + 产量变化比例）。默认126 MWh、未来七天、产量增长5%，结果132.3 MWh。
- 单位电耗 = 电量 / 产量，超过基准5%提示关注。示例中老化单耗13.5 kWh/千只，基准12，偏高12.5%。
- 问答按用户输入识别工序、天数和产量变化，用上述规则生成普通文字。尚未调用真实模型。
- 估算线不是实测历史曲线；当前不能识别每日突增、非生产时段异常或班次差异。

## 简化后的页面

保留“业务看板 / 智能问答”两个模式入口。看板上工序、估算天数与产量变化直接调整并重算，不用打开设置或点击应用。切到问答时带入当前看板条件；返回看板时同步问答中有效的估算条件，历史回答不变。显示统计用电、估算用电、需关注工序三项概览，以及用电估算、工序电量对比、单位电耗和异常说明。

删除重复的问问助手、导出、设置弹层、图表和明细的查看/分析按钮、全部明细页签、查看数据入口。问答使用普通文本，说明数据来源与估算口径；没有重复的结果卡片、指标标签、操作按钮和快捷追问。

真正补齐原文的趋势、班次、非生产时段异常及多能源分析，还需带时间与运行状态的对应明细数据。本轮只核对现状并精简页面，不把缺失数据包装成已经实现的功能。
