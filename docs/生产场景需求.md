# 第四场景：生产洞察与预警

支持不少于5个核心指标展示，以及5类自然语言问数或异常提醒。前端先使用当前资料计算，回答按问题组织为普通文字、段落或必要列表，来源统一放在文末。

## 核心指标

看板保留现有五项指标，共用所选产线与指标规则。

| 指标 | 计算口径 | 当前全范围示例 |
| --- | --- | --- |
| 实际产量 | 各产线实际产量求和 | 37.3万只 |
| 计划完成率 | 总实际产量 ÷ 总计划产量 × 100% | 93.25% |
| 检验良率 |（总检验数 − 总不良数）÷ 总检验数 × 100% | 98.35% |
| 累计停机 | 各产线停机分钟数相加 | 140分钟 |
| 异常产线 | 完成率低于目标，或不良率超过上限的产线数量；同一产线只计一次 | 1条 |

固定完成率目标95%，不良率上限2%，不支持页面配置或通过对话修改。等于边界不触发异常。总计划40万只，计划缺口2.7万只；检验数4万只、不良数660只，不将检验样本的合格数量当作全部生产的合格产量。

看板底部直接展示一张产线明细表：产线、计划产量、实际产量、完成率、不良率、停机分钟、是否异常和异常说明。是否异常显示“是/否”，正常产线的异常说明留空。表头说明当前异常阈值，支持“全部/异常/正常”下拉筛选；该筛选只影响明细列表，上方指标和图表仍按所选产线范围统计。明细随产线筛选更新，没有匹配记录时显示空结果说明。不再提供明细标签页、逐行分析或查看入口，也不展示节拍、在制品、班次的无数据占位区。

## 五类自然语言示例

| 类别 | 示例问题 | 回答内容 |
| --- | --- | --- |
| 产量与进度 | 全部产线计划多少、实际生产多少，完成率多少，还差多少？ | 计划、实际、完成率、计划差额 |
| 检验质量 | 哪些产线不良率超过2%，综合检验良率是多少？ | 检验数、不良数、加权良率/不良率及质量异常 |
| 停机情况 | 各产线累计停机多久，哪条停机最多？ | 停机汇总、各线停机时长及排序 |
| 产线对比 | 比较1号产线和3号产线的完成率与质量 | 按指定产线比较实际数据，不混入未选择的产线 |
| 异常提醒与解释 | 检查全部产线的综合异常，并说明需要优先核查哪些产线。 | 按固定规则列出异常产线、具体数值、判断规则和核查建议 |

欢迎页保留三个问题卡片：生成生产日报、比较产线表现、检查综合异常。五类能力不与卡片数量绑定；询问“你能做什么”时以普通文本给出完整五类示例及生成日报的提问方式。

## 生成生产日报

点击“生成生产日报”发送“生成当前产线范围的生产日报，汇总产量、质量、停机和异常，并给出跟进建议。”也支持直接输入“生成日报”或指定产线。日报沿用当前单选或多选范围，明确指定范围时更新选择。

回复通过共用对话组件流式输出普通 Markdown：统计范围与日期说明、计划和实际产量、完成率及差额、检验数与不良数、加权良率与不良率、累计停机与重点产线、按固定规则识别的异常，以及相应核查建议。来源仅在文末展示。仍使用原有处理摘要折叠、点赞、点踩和复制，不增加报表页面、定制卡片或报告导出入口。

当前数据没有日期字段，生成时明确“统计日期待确认”，只汇总现有记录，不能把生成当天或用户指定的日期认定为数据所属日期。确认统计日期需有对应日期的生产资料。部分指定产线不存在时说明缺失范围，只有空记录时不生成无依据的日报；不推断停机或质量偏差的确定原因，不把检验合格数量当作全部合格产量。

多轮对话保留当前产线，支持通过追问切换范围。阈值固定使用默认值；旧草稿中的自定义规则在继续使用时恢复默认，历史回答保留原结果。来源标明当前资料名或原文件名，不展示示例标签；不为没有文件路径的资料生成虚构链接。

## 输出与历史兼容

新回答不返回用于展示的定制分析卡片，不显示参数标签、图表、明细标签页或保存分析按钮。回答末尾保留点赞、点踩、复制；问题保留复制。输入区以自然语言提问和发送为主。

旧对话里的分析对象只在阅读时转换为文本，保留当时的数值与计算依据，不用新资料重新计算历史结果。历史对话与生产业务看板保持可访问，独立分析记录模块已移除。

## 数据边界

当前样例为4条产线汇总，包含产线、计划产量、实际产量、检验数量、不良数量、停机时长。没有日期、班次、设备事件、开动时长或停机原因，不输出趋势、同比环比、班次分析、OEE、停机率或确定的故障原因。

异常提醒指当前查询与看板按规则标出的待核查记录，不代表已发送消息、已建立定时监控或已自动处理。当前回复由前端资料与规则生成。
